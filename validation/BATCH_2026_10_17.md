## `opls_141` fix (2026-10-17)

`FOYER_SUPPLEMENTARY_DEFINITIONS["opls_141"] = "[C;X3](C)(C)=C"` replaces
Foyer's `[C;X3;!r6](C)(C)C`. No new atom type: the same `opls_141` (CM) is
assigned, with an explicit C=C instead of the ring exclusion. Foyer matches
bond orders and RDKit passes aromatic bonds as 1.5, so aromatic carbons cannot
match. One behaviour narrows: an X3 carbon with three C neighbours in an
aromatic non-six-membered ring (old pattern matched) no longer matches; such a
carbon should not be an alkene CM anyway.

Checks: new unit test (limonene ring and isopropenyl C, linalool, toluene ipso
C stays `opls_145`); 30/30 tests pass; all 39 previously passing molecules give
byte-identical ITPs, atom types and charges.

LigParGen check (`molecules_to_test/limonene.itp`; `limonene.sdf` was built in
LigParGen atom order by graph isomorphism, `benchmarks/limonene/`): LigParGen
also types the ring C(CH3)= as plain CM with alkene LJ and the standard CM
bonded terms, the same as the acyclic R2C=. Our ring carbon now matches it in
class, LJ, bonds and angles. Benchmark: bonds 26/26, angles 47/48, propers
59/65, impropers 0/4, pairs 62/62, same interaction set. Differences:

- Ring vinyl H: LigParGen class HA (σ 0.242), workflow HC/`opls_144` (σ 0.242).
  This causes the angle CT-CM-HA (LigParGen 118.77°/482.666, a BOSS default;
  workflow CT-CM-HC 117°/292.88) and the torsion CT-CT-CM-HA (LigParGen
  −33.472/+33.472, a 90°-favouring twofold term; workflow zero-torsion).
- The =CH2 H: LigParGen σ 0.250 (generic HC), workflow `opls_144` σ 0.242.
- CM-CT-CT-CM (ring): LigParGen uses the CT-CT-CT-CT values; workflow zero-torsion.
- CT-CT-CT-CT/CM and CM impropers: known table differences.
- Charges: MAE 0.0049 e, max 0.021 e, higher than earlier benchmarks. AMSOL
  runs a fixed-geometry single point, and this geometry is ETKDG+MMFF, not
  LigParGen's (none was available), so this is likely conformer-driven. Not verified.

Carvone also types now but needs 14 fallback terms (10 zero-torsion) around
the enone and ring; see `benchmarks/batch_2026_10_17_opls141/carvone/`.

## LigParGen comparison: lidocaine, coumarin, methyl salicylate (2026-10-17)

LigParGen ITPs: `molecules_to_test/{lidocaine,coumarin,methylsalicylate}.itp`.
SDFs in LigParGen atom order were built with `src/scripts/reorder_to_itp.py`.

Foyer candidate types). Per-term: `src/scripts/compare_ligpargen_terms.py NAME
ATOMS` (LigParGen terms vs the GROMACS table looked up with LigParGen's classes).

- **Lidocaine, N-CH2-C(=O) (LigParGen atom 2):** class CT with generic CT LJ.
  All 34 terms touching it are in the GROMACS table with identical values,
  except torsion NT-CT-C-N (LigParGen RB 11.82/−6.736/−9.017/3.933), which is
  not in the table.
- **Coumarin:** LigParGen treats the pyranone ring as a non-aromatic lactone.
  - Carbonyl C is class C, carbonyl O is class O, and ring O is OS.

    LigParGen's ester side.

    LigParGen's classes (`C=`, CB-C=, HA-CM, CM-C-OS).
- **Methyl salicylate:**
  - LigParGen: C/O/OS. Workflow: C (`opls_471`)/O_2 (`opls_466`)/OS.

## `terminal-ct-alias` fallback rule (2026-10-17, user approved)

New boss-like rule (`bonded.py`, `_terminal_ct_alias_rule`), tried after
`class-alias` and `central-class-average`, before `zero-torsion`. For proper
torsions only, an end-position (1 or 4) CA or CM is read as CT: one end first,
then both. Central atoms are never substituted, so BOSS closest-mismatch is
still not reproduced. ITP lines are marked `; terminal-ct-alias`. 32/32 tests
pass (transfluthrin: 1 terminal-ct-alias, 2 zero-torsion).

## Closest-mismatch and residual torsion fitting (2026-10-17, option 3)

**How BOSS handled isoniazid's N–N bond.** All four torsions in LigParGen are
RB 0.6276/1.8828/0/−2.5104, a 3-fold term of 0.3 kcal/mol. These equal the
GROMACS hydrazine entries H-NT-NT-H and CT-NT-NT-H, so BOSS's closest-mismatch
substituted amide N→NT (central) and C→CT.

## Torsion archive with DFT fitting (2026-10-17)

User decisions:
- Entries are keyed by class quartet **and** a SMARTS context.
- The archive is used in strict mode as well.
- Heavy-atom quartets carry the fitted term.
- Fitting uses a low-level DFT for now, to test the workflow; the archive can
  be regenerated at a higher level later.

**PySCF:**
- The conda-forge package was unsolvable in the `openMM` env (`xcfun`
  dependency).
- Installed with pip instead: `pyscf` 2.14.0, `pyscf-dispersion` 1.5.0 and
  `h5py` 3.16.0. numpy, scipy and the other packages were unchanged.
- `pip check` is clean and all tests pass.
- Pre-install env snapshots are in this session's scratchpad
  (`openMM_env_before_pyscf.txt`, `openMM_pip_before_pyscf.txt`).

**Method:** B3LYP-D3(BJ)/def2-SVP, density fitting, single points on
GFN2-xTB constrained scan geometries. Each point takes 3.7 s for isoniazid
(17 atoms) and 21 s for fluconazole (34 atoms) on 10 threads, measured with a
monotonic clock. Wall-clock timings via `time.time()` jumped by about 7,300 s
in this WSL session, so earlier xTB timing numbers are unreliable.

**Implementation:**
- `src/opls_ff_gen/archive.py` and `data/torsion_archive.json`.
- Archive lookup in `bonded.py` (rule `archive`, `source_id`); CLI options
  `--torsion-archive`/`--no-torsion-archive`.
- `torsion_fit.py` additions: `--qm dft`, `--fallback-bonds`, `--archive`,
  only missing torsions zeroed, shared fit over the carrier quartets.
- Tests: 45/45 (archive context, strict-mode use, duplicates/ambiguity,
  round trip, shared fit).

**Isoniazid** (`benchmarks/isoniazid/torsion_fit/`), DFT, 95 s per bond:

| Bond | Carriers | DFT barrier | RMSE fallback → fitted |
|---|---|---:|---|
| Amide C–N (2-9) | CA-C-N-NT, O-C-N-NT | 104.6 | 17.4 → 2.6 |
| N–N (9-10) | C-N-NT-H ×2 (no all-heavy quartet) | 34.8 | 8.5 → 2.1 |

- Archived entries: `CA-C-N-NT`, `O-C-N-NT`, `C-N-NT-H` (fitted) and
  `H-NT-N-H` (zero by convention).
- Regenerated isoniazid: all 6 former fallback torsions come from the
  archive; the N–N warning is gone.
- **Reuse:** benzohydrazide (never fitted) reads all 6 entries. Acetohydrazide
  reads the 4 N–N entries, but not the amide C–N ones: there the carbonyl C's
  neighbour is aliphatic, so the context differs. It keeps 2 zero torsions
  until that context is fitted.
- **Batch** (`benchmarks/batch_2026_10_17_archive/`, now current): 50/50 pass
  grompp with 0 warnings; only isoniazid changed.

**Caveats:**
- The fit is shared over carriers with different classes (CA-C-N-NT and
  O-C-N-NT get identical coefficients). It reproduces the scan, but the
  split between them is a convention, not physics.
- Charges are per molecule, so archived residuals transfer only
  approximately.
- Ring bonds are not handled.
- The level of theory is low.
